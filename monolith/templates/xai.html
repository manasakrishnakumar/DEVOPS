2. Climate Extreme Score (CES) Analysis

CES Formula (WMO SPI, WMO-No. 1090, 2012): CES = 0.6×Z_rainfall + 0.4×Z_temperature
Humidity removed from CES due to multicollinearity (physically coupled to rainfall & temperature)
• CES ≥1.300 → Extreme Climate (95th percentile)
• 1.051 ≤ CES < 1.300 → Moderate Climate (84th–95th percentile)
• CES < 1.051 → Normal Climate (below 84th percentile)
CES Timeline with Decade Peaks
Key Observations: The red dots mark the highest CES peak in each decade. Notice the increasing trend in peak values, especially from 2000 onwards, indicating rising climate extremeness.

The 84th percentile defines “Moderate” and the 95th percentile defines “Extreme”, following the WMO Standardized Precipitation Index methodology (WMO-No. 1090, 2012).
